# ICP and personas

Build the ICP from won deals, not from guesses: profile every closed-won deal for segment, role, research area and product, then write one card per segment.

## ICP card template
| Field | Notes |
|---|---|
| Segment | Who buys (e.g. organ-on-chip developers) |
| Why they buy | The job the product does for them |
| Buyer personas | Economic buyer, technical evaluator, user, procurement |
| Research areas | Topics that signal relevance |
| Trigger events | What makes them ready now |
| Disqualifiers | Too small, wrong region, competitor, student-only accounts |
| Best first product | The easiest entry offer |
| Proof | Customer type, application data, protocol |

## Example card (fictional)
| Field | Value |
|---|---|
| Segment | Organ-on-chip developers |
| Why they buy | Need reproducible vascular cells to build barrier and perfusion models |
| Buyer personas | Head of R&D (decision), scientist (evaluator), procurement (order) |
| Research areas | Endothelial, barrier models, perfusion, microphysiological systems |
| Trigger events | New grant award, new paper on vascular models, hiring a cell-culture scientist, pricing-page visit |
| Disqualifiers | Student-only contact, competitor domain, existing tiny account |
| Best first product | Starter cell vial plus expansion medium kit |
| Proof | Application note, protocol, one reference customer type |

## Persona field
Fill a Persona property on every contact so scoring and nurture can use it: decision-maker, evaluator, user, procurement. Keep one decision-maker per account plus at most one escalation contact.
